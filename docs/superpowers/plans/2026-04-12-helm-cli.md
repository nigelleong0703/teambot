# Helm CLI Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the existing TUI from "TeamBot Workbench" to "Helm", switch to a blue color palette, add persistent input history, and wire up `cli.py` at the root to launch it.

**Architecture:** `src/teambot/app/tui.py` already has `TeamBotTuiApp` + `TranscriptRenderer` using ANSI codes, a `✻ Thinking...` animation, and a prompt_toolkit input layer (`tui_input.py`). No library change needed — just update the color palette, branding strings, and history config in the existing files.

**Tech Stack:** Python 3.11+, `prompt_toolkit` (already installed), raw ANSI escape codes (already in use)

**Note:** `requirements.txt` is NOT changed — `rich` is not added. The existing ANSI renderer in `tui.py` already handles all color output; the spec's `rich` dependency is superseded by the as-built approach.

```python
def test_build_tui_input_reader_uses_file_history(tmp_path, monkeypatch):
    """PromptToolkitInputReader should use FileHistory, not InMemoryHistory."""
    monkeypatch.setenv("HOME", str(tmp_path))
    # No importlib.reload needed — Path.home() is called at build_tui_input_reader() call time
    from teambot.app.tui_input import build_tui_input_reader

    reader = build_tui_input_reader(use_color=False)
    # If prompt_toolkit not available, will be PlainInputReader — skip
    if reader.__class__.__name__ == "PlainInputReader":
        pytest.skip("prompt_toolkit not installed")

    history = reader.session.history
    assert "InMemoryHistory" not in type(history).__name__, \
        "Expected FileHistory, got InMemoryHistory"
    assert hasattr(history, "filename"), "Expected FileHistory with .filename attribute"
```
